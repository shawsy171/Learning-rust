# Learning Rust

A Cargo workspace for working through Rust from the ground up.

- `modules/` — one crate per module (`m01_basics`, ...), exercises + tests
- `notes/` — lesson notes in Markdown, plus [`key-things-to-remember.md`](notes/key-things-to-remember.md), a running cheat sheet of the big ideas

Run everything: `cargo test` from the repo root. One module: `cargo test -p m01_basics`.
